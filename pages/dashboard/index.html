🪙 积分获取

签到 / /checkin：每日打卡，附赠今日运势与连签/首签加成。

查积分 / /points：查询个人资产卡片与护盾库存。

积分榜 / /points_rank：查看群内或全局富豪排行榜。

⚔️ 禁言与封印

/禁言 @群友 [时长]：消耗积分对其施加禁言封印。

自闭 [时长] / /selfmute：自我禁言冷静，享受半价优惠。

/解禁 @群友 / /unmute：花费积分提前解除禁言。

/轮盘赌 @群友 [赌注]：50% 胜率对赌禁言决斗。

🛡️ 道具与转账

买护盾 [数量] / /buy_shield：购买禁言护盾抵挡封印并概率反弹。

我的护盾 / /my_shield：查看持有的护盾数量。

/转账 @群友 数量：向好友赠送积分。
