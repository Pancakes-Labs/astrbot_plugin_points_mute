# AstrBot 积分签到与禁言系统插件 (astrbot_plugin_points_mute) 🐱

丰富有趣的 AstrBot 积分经济体系插件！支持每日签到领积分、运势系统、连续签到加成、积分禁言群友、自闭/冷静模式、禁言护盾与反弹、俄罗斯轮盘赌对决、积分转账赠送以及超全的自定义配置项喵~

---

## ✨ 核心特性

1. 🌟 **每日签到与运势**
   - 每日签到随机获得基础积分。
   - 运势系统（超大吉、大吉、中吉、小吉、平、末吉、凶）附带吉凶签语，并可配置运势积分加成。
   - 连续签到递增奖励机制，坚持打卡奖励更多。
   - 每日群内前三名（状元/榜眼/探花）专属额外加成。

2. ⚔️ **积分禁言与自闭玩法**
   - 群友互封印：花费积分禁言指定成员（支持自定义分钟/小时/天）。
   - 自闭/冷静模式：自己禁言自己，专心学习工作，享受半价折扣。
   - 积分赎身：花费积分提前解除他人或自己的禁言。
   - 机器人反噬防卫：试图禁言机器人会被神罚反弹禁言并没收罚金。
   - 权限失败自动退款：若机器人权限不足禁言失败，自动全额退款。
   - **四维上限与防集火保护**：
     - 单人每日发起禁言次数上限（防止富豪群友狂刷禁言）。
     - 单人每日被禁言次数上限（防集火保护，达标后免疫当日禁言）。
     - 单人每日累计被禁言总时长上限（如每日最多被封 2 小时）。
     - 全群每日禁言总次数上限（防止群内过度混乱）。

3. 🛡️ **禁言护盾与反弹机制**
   - 可以在商城购买禁言护盾保命。
   - 被人施加禁言时自动消耗一层护盾抵挡封印。
   - 拥有概率触发【绝对反弹】，将禁言反弹给施术者！

4. 🎰 **俄罗斯轮盘赌对决**
   - 发起者下注积分挑战指定群友。
   - 50% 胜率对决：赢了禁言对方并赢取双倍彩金，输了炸膛反噬禁言自己并没收赌注。

5. 💸 **积分转账与经济体系**
   - 支持群友间积分转账赠送，支持自定义转账手续费率（系统回收）。

6. 🏆 **风云排行榜**
   - 积分富豪榜：支持群内/全局排行。
   - 连续签到榜：展示群内打卡肝帝。

7. 🗄️ **SQLite 嵌入式数据库与群数据隔离**
   - 底层采用高性能 SQLite 数据库（`points.db`），持久化存放在 `data/plugin_data/` 目录。
   - 默认启用**群独立隔离模式**（`group_isolated`）：同一个 QQ 号在不同群拥有各自独立的积分资产、签到天数和排行榜！
   - 支持一键切换为全局共享模式（`global_shared`）。

8. ⚙️ **数十项丰富配置**
   - 货币名称（积分、喵币、金币等）、单位、群隔离模式、各项倍率、价格、时长上下限、各文案模板均可在 AstrBot 管理面板可视化配置！

## ⚙️ 配置项说明（部分精选）

在 AstrBot 管理面板或 `_conf_schema.json` 中可自由配置：

- `currency_name`: 积分名称（默认“喵币”）
- `currency_unit`: 积分单位（默认“个”）
- `allow_no_prefix`: 是否允许无斜杠前缀指令（如直接发“签到”、“查积分”）
- `checkin_min_points` / `checkin_max_points`: 每日基础签到积分随机范围
- `checkin_streak_bonus_per_day`: 每天连续签到额外加成
- `checkin_first_bonus` / `checkin_second_bonus` / `checkin_third_bonus`: 每日群前三名额外奖励
- `checkin_luck_enabled` / `checkin_luck_affects_points`: 运势系统与积分加成开关
- `mute_cost_per_minute`: 禁言每分钟消耗积分
- `mute_default_duration` / `mute_min_duration` / `mute_max_duration`: 单次禁言时长范围
- `daily_user_mute_limit`: 单人每日发起禁言次数上限（默认 5，0 为不限）
- `daily_user_muted_limit`: 单人每日被禁言次数上限 / 防集火保护（默认 5，0 为不限）
- `daily_user_muted_max_duration`: 单人每日累计被禁言总时长上限（秒，默认 7200 即 2 小时）
- `group_daily_mute_total_limit`: 全群每日禁言总次数上限（默认 50，0 为不限）
- `mute_bot_defense`: 试图禁言机器人反噬开关
- `shield_enabled` / `shield_price` / `shield_max_hold` / `shield_reflect_chance`: 禁言护盾配置
- `roulette_enabled` / `roulette_win_rate`: 轮盘赌对决配置
- `transfer_fee_rate`: 积分转账手续费率
- `custom_checkin_title` / `custom_mute_success_msg` / `custom_shield_broken_msg`: 自定义提示文案模板
